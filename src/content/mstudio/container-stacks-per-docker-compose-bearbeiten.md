---
title: Container-Stacks per Docker Compose bearbeiten
date: 2026-08-21
---
Ab sofort kannst du einen Container-Stack im mStudio im **Docker Compose-Format** bearbeiten. Statt jeden Container einzeln über Formulare zu konfigurieren, beschreibst du den ganzen Stack an einer Stelle. Du findest die Funktion im Projekt unter **Container** → **Stacks**: Stack auswählen und auf **Compose bearbeiten** klicken.

**Highlights auf einen Blick:**

- Kompletten Stack einfach im Code-Editor bearbeiten – Services, Images, Ports, Umgebungsvariablen und Volumes
- Bestehende Compose-Datei per Upload nutzen
- Aktuelle Konfiguration herunterladen, um den Stack lokal oder auf einem anderen Server zu starten
- Validierung vor dem Speichern: aktuell sind noch nicht alle Docker Compose-Optionen möglich
